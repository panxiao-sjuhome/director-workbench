# 导演工作台（参考图复刻版）

这是根据用户提供的深色影视/AI 视频工作台截图制作的可操作网页原型。

## 已实现

- 深色科技感四栏布局：导航、分镜列表、中央预览/时间轴、右侧镜头参数
- 5个示例分镜，可点击切换
- 中央 Canvas 雨夜城市预览，支持播放/暂停和进度拖动
- 多轨道时间轴：画面、声音、字幕
- 时间轴片段点击联动当前分镜
- 镜头描述编辑与字数统计
- 运动强度滑块
- 生成当前镜头演示状态
- 新建镜头、添加分镜、排序、缩放时间轴
- 保存到浏览器 localStorage
- 导出项目 JSON
- 右侧参数状态同步
- 在窄屏宽度下保留四栏结构并压缩显示

## 说明

这是根据截图进行的视觉与交互复刻原型，不是 MiniMax 官方产品，也没有接入真实视频生成 API。中央雨夜画面为本地 Canvas 演示场景，后续可以替换为真实视频、图片序列或生成任务结果。
